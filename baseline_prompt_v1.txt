# Machine Learning: Overfitting and Regularization

## 1. Overfitting
Overfitting occurs when a machine learning model learns the training data too closely, including noise and unimportant patterns. An overfitted model may perform very well on training data but poorly on unseen data.

## 2. Underfitting
Underfitting occurs when a model fails to learn the important patterns in the training data. An underfitted model typically performs poorly on both training data and unseen data.

## 3. Regularization
Regularization is a technique used to reduce overfitting by discouraging excessive model complexity. It can help a model generalize better to unseen data.

## 4. Cross-Validation
Cross-validation evaluates a model by splitting available data into training and validation portions across multiple rounds. It helps estimate how well the model may perform on data not used to fit it.

## 5. Other Methods to Reduce Overfitting
Other methods include collecting more representative training data, pruning decision trees, and using dropout in suitable neural networks.

## 6. Generalization
Generalization is a model's ability to perform well on new, unseen examples. A useful machine learning model should learn meaningful patterns rather than simply memorizing its training data.
