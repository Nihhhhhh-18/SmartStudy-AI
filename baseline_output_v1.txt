# Study Pack: Machine Learning — Overfitting and Regularization

## 1. Summary

### 1.1 Overfitting

Overfitting occurs when a machine learning model learns the training data too closely, including noise and unimportant patterns.

- The model performs very well on training data.
- It performs poorly on unseen data.
- The model memorizes the training data instead of learning meaningful patterns.

### 1.2 Underfitting

Underfitting occurs when a model fails to learn the important patterns in the training data.

- The model performs poorly on training data.
- It also performs poorly on unseen data.
- The model has not learned the important patterns sufficiently.

### 1.3 Regularization

Regularization is a technique used to reduce overfitting by discouraging excessive model complexity.

Its main purpose is to help the model generalize better to unseen data.

### 1.4 Cross-Validation

Cross-validation is a method for evaluating a machine learning model.

- The available data is divided into training and validation portions.
- This process is repeated across multiple rounds.
- It helps estimate how well the model may perform on data that was not used to train it.

### 1.5 Other Methods to Reduce Overfitting

Three additional methods mentioned in the notes are:

1. Collecting more representative training data: Provides the model with more representative examples.
2. Pruning decision trees: A method that can help reduce overfitting.
3. Using dropout: A method used in suitable neural networks to help reduce overfitting.

The notes do not explain the detailed implementation of these methods.

### 1.6 Generalization

Generalization is a model's ability to perform well on new, unseen examples.

A useful machine learning model should learn meaningful patterns rather than simply memorize its training data.

## 3. Practice Questions

### Question 1 — Multiple Choice

Which situation best describes overfitting?

A. A model performs poorly on both training and unseen data.

B. A model performs well on training data but poorly on unseen data.

C. A model performs equally well on all data.

D. A model is evaluated across multiple rounds.

Answer: B. Overfitting occurs when a model learns the training data too closely and performs poorly on unseen data.

### Question 2 — Short Answer

What is the difference between overfitting and underfitting?

Answer:

- Overfitting: The model performs very well on training data but poorly on unseen data because it learns noise and unimportant patterns.
- Underfitting: The model fails to learn important patterns and performs poorly on both training and unseen data.

### Question 4 — Scenario-Based Question

A student trains a machine learning model. It performs very well on the training data but performs poorly on new examples. The student wants to improve the model's ability to perform well on unseen data.

a) What problem is the model experiencing?

b) Name two methods from the lecture notes that could help reduce this problem.

Answer:

a) The model is experiencing overfitting.

b) Two possible methods are:

- Regularization
- Collecting more representative training data

Pruning decision trees and using dropout in suitable neural networks are other methods mentioned in the notes.

### Question 5 — True or False

Cross-validation helps estimate how well a model may perform on data not used to fit it, while generalization refers to the model's ability to perform well on new, unseen examples.

Answer: True.

Cross-validation is an evaluation method, whereas generalization is the ability to perform well on unseen examples.

Exam tip: Remember the key distinction: overfitting = good training performance, poor unseen-data performance; underfitting = poor performance on both. Regularization and cross-validation address different concerns: regularization helps reduce overfitting, while cross-validation helps estimate model performance.
